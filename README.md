# 🚗 Automobile Data Analysis (Exploratory Data Analysis)

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a used automobile dataset to uncover market trends and identify the key factors influencing vehicle resale prices.

Using Python's data analysis and visualization libraries, the project cleans the dataset, explores relationships between vehicle attributes, and generates actionable business insights that can assist dealerships, buyers, and sellers in making informed decisions.

---

## 🎯 Project Objectives

- Clean and preprocess raw automobile data.
- Handle missing values and duplicate records.
- Explore relationships between vehicle features and selling prices.
- Identify market trends through visualizations.
- Generate business insights and recommendations from the data.

---

## 📂 Dataset Description

The dataset contains information about used vehicles, including:

- 🚗 Brand
- 🚙 Model
- 📅 Manufacturing Year
- ⛽ Fuel Type
- ⚙️ Transmission
- 🔧 Engine Size
- 🏎 Horsepower
- 🔩 Torque
- 🛣 Mileage
- 💰 Selling Price
- 🎨 Color
- 🛠 Service History
- 🚨 Accident History
- 📍 Location

---

# 🛠 Data Preprocessing

To ensure high-quality analysis, the following preprocessing steps were performed:

- Removed duplicate records.
- Identified missing values across multiple columns.
- Filled missing numerical values using the **Median**.
- Filled missing categorical values using the **Mode**.
- Verified that no missing values remained after preprocessing.
- Prepared the dataset for visualization and analysis.

---

# 📊 Exploratory Data Analysis (EDA)

The following analyses and visualizations were performed:

- Selling Price Distribution
- Correlation Heatmap
- Top 10 Car Brands
- Fuel Type Distribution
- Transmission Analysis
- Manufacturing Year Distribution
- Mileage vs Selling Price
- Engine Size vs Selling Price
- Horsepower vs Selling Price
- Boxplots for Outlier Detection
- Pairplot for Numerical Features

These visualizations helped uncover relationships between different vehicle characteristics and their influence on resale prices.

---

## 🔍 Key Findings

- 🚗 Ford is the most frequently listed brand in the dataset.
- ⛽ Petrol vehicles dominate the used car market.
- 💰 The average vehicle selling price is **12,319.87**.
- 📅 Vehicles manufactured between **2005 and 2024** are included.
- 🏷 The dataset contains **10 brands** and **40 unique models**.
- 🛣 The average vehicle mileage is **114,529.48 km**.
- ⚙ Medium-sized engines (average **2.44 L**) are the most common.
- 📈 Vehicle age, mileage, engine size, and horsepower all influence resale value.

---

# 💼 Business Recommendations

Based on the analysis:

- Focus inventory on high-demand brands such as **Ford**.
- Maintain sufficient stock of **Petrol** vehicles while monitoring the growing market for alternative fuel vehicles.
- Develop pricing strategies based on:
  - Vehicle age
  - Mileage
  - Engine size
  - Horsepower
- Buyers should compare mileage and manufacturing year before purchasing.
- Sellers can improve resale value by maintaining complete service records and regular vehicle maintenance.
